# The 3D companions (shelved)

Before the pixel art (October 2026) the companions were built in three.js: procedural,
cel-shaded figures with ink outlines, rendered by `Stage.ts`, plus `Cat.tsx`, the flat SVG
cat that stood in without WebGL. They were replaced because the faces never got cute
enough. Kept here for reference only; nothing imports them and they are not built.
