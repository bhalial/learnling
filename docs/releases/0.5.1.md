## What's new

**Look further ahead.** In Settings, *Looking ahead* sets how many weeks your planner reaches: from 2 up to 10. Set it above 2 and arrows appear at the top of the pages, so you can turn the book a week at a time. Magister is read that far ahead as well. It starts at 2, so nothing changes until you choose more.

**Choose how long you practise for a test.** In Settings, *Practising for a test* sets how many days before a test and before a quiz you practise, one practice round a day. Pick anything from 0 (no practice rounds) to 10; it used to be 3 for a test and 2 for a quiz. Tests already in your planner change along with it. Rounds you ticked off stay, and so does a round you dragged to another day.

### Fixed

- When a test moved after all its practice rounds were ticked off, a new round showed up on every school day before it. Now it gets none.
- "1 practice rounds" now says "one practice round", in every theme.

### Updating

The Windows app updates itself. The Chrome extension updates through the Chrome Web Store once the new version is live there.

## Wat is er nieuw

**Verder vooruitkijken.** Bij Instellingen zet je onder *Vooruitkijken* hoeveel weken je planner vooruit gaat: van 2 tot 10. Kies je meer dan 2, dan komen er pijltjes bovenaan de bladzijden en blader je per week verder. Magister wordt dan ook zo ver vooruit gelezen. Het staat op 2, dus er verandert niets tot je zelf meer kiest.

**Zelf kiezen hoe lang je oefent voor een toets.** Bij Instellingen zet je onder *Oefenen voor een toets* hoeveel dagen je vóór een toets en vóór een SO oefent, elke dag één oefenronde. Kies van 0 (geen oefenrondes) tot 10; eerst was het altijd 3 voor een toets en 2 voor een SO. Toetsen die al in je planner staan veranderen mee. Afgevinkte rondes blijven staan, en een ronde die je naar een andere dag hebt gesleept ook.

### Opgelost

- Verschoof een toets nadat je alle oefenrondes al had afgevinkt, dan kwam er op elke schooldag ervoor een nieuwe ronde bij. Nu niet meer.
- "1 oefenrondes" heet nu "één oefenronde", in elk thema.

### Bijwerken

De Windows-app werkt zichzelf bij. De Chrome-extensie wordt bijgewerkt via de Chrome Web Store, zodra de nieuwe versie daar live staat.
