Privacy

  • Alles blijft op je eigen apparaat. Het huiswerkboek staat in Chrome, in de opslag van de extensie (of in de Windows-app op de computer zelf). Er gaat niets naar een server van ons; er is geen server.
  • Magister: alleen lezen, en alleen als je het zelf koppelt. Chrome vraagt dan eerst om toestemming voor magister.net. Learnling leest je lessen, huiswerk en toetsen met de inlog die Magister zelf in je browser bewaart. Het toegangstoken van Magister blijft alleen in het geheugen en verdwijnt als Chrome sluit. Learnling bewaart geen wachtwoord en verandert nooit iets in Magister.
  • Geen trackers, geen reclame, geen account. Er wordt niets verzameld, gemeten, gedeeld of verkocht.
  • Stoppen kan altijd. Instellingen → Magister → Ontkoppel trekt ook de toestemming voor magister.net in. Wie de extensie verwijdert, wist daarmee het hele boek.
  • Vragen? Stel ze op GitHub, waar ook alle code staat.

Privacy

  • Everything stays on your own device. The homework book lives in Chrome, in the extension's storage (or, in the Windows app, on the computer itself). Nothing goes to a server of ours; there is no server.
  • Magister: read only, and only when you connect it yourself. Chrome first asks permission for magister.net. Learnling reads your lessons, homework and tests with the login Magister itself keeps in your browser. Magister's access token is kept in memory only and is gone when Chrome closes. Learnling stores no password and never changes anything in Magister.
  • No trackers, no ads, no account. Nothing is collected, measured, shared or sold.
  • You can stop any time. Settings → Magister → Disconnect also takes back the permission for magister.net. Removing the extension erases the whole book.
  • Questions? Ask them on GitHub, where all the code is too.
